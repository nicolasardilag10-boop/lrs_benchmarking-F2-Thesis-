# Archive

This directory preserves material that is no longer a canonical execution or analysis entry point.

- `legacy/`: retired workflows and repository-maintenance scripts.
- `migration_snapshots/`: point-in-time repository migration records.
- `backups/`: local safety backups.
- `tutorials/`: non-production training material.
- `unclassified/`: artifacts retained because deletion was not scientifically justified.
- `duplicates/`: redundant copies preserved temporarily for provenance.

Archived code should not be imported or executed by maintained workflows. When a historical file is needed, copy its useful logic into an active, documented location and test it there.
