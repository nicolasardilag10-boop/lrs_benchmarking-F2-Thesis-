# Cross-project figures

Figures specific to one benchmark should normally live with that analysis module:

- alignment: [`../alignment_analysis/figures/`](../alignment_analysis/figures/)
- assembly: [`../assembly_analysis/figures/`](../assembly_analysis/figures/)
- variant calling: [`../variant_calling_analysis/figures/`](../variant_calling_analysis/figures/)

This directory is reserved for cross-project or historically shared visualizations. The current standalone SV F1 plot is in [`variants/sv_f1_barplots.png`](variants/sv_f1_barplots.png). R Markdown sources retained here are exploratory sources, not the canonical alignment plotting pipeline.
