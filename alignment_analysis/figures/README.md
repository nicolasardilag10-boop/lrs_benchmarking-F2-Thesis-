# Alignment figures

## Current production figures

Use [`30x/final/`](30x/final/) for the selected 30× figure set and [`30x/README.md`](30x/README.md) for the figure-to-script map.

## Other figures

- `30x/exploratory/`: 30× diagnostics and alternative presentations.
- `30x/archive/`: superseded 30× drafts.
- Files directly in this directory are earlier 1k or development figures retained for provenance. They are not the current report figure set.

Final figures should be saved as both PDF (publication/report use) and PNG (quick review). Use numbered, descriptive names.
