# Alignment tables

## Current production table

The canonical 30× table is [`30x/final/alignment_benchmark_30x.tsv`](30x/final/alignment_benchmark_30x.tsv). Its source, derived, and archive structure is explained in [`30x/README.md`](30x/README.md).

## Earlier tables

Files directly in this directory primarily support the earlier 1k analysis and raw per-sample metric extraction. They remain in place for compatibility with legacy scripts. Superseded snapshots and mixed-coverage summaries are under `archive/`.

Do not select a table only because its name contains `final`. Confirm the canonical path in this README or the project [`FILE_INDEX`](../../docs/FILE_INDEX.md).
