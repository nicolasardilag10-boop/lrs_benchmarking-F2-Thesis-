# Generated results

This directory provides organized result groupings and links. Some entries are symbolic links to established output locations so active workflows do not need path changes.

| Directory | Contents |
|---|---|
| `alignment/` | alignment workflow outputs |
| `assembly/` | assembly outputs |
| `variants/` | variant-calling outputs and links |
| `metrics/` | quality and run metrics |
| `benchmarking/` | benchmark summaries |
| `validation/` | validation result links, including hap.py |

Canonical analysis-ready tables and figures remain inside the relevant analysis module rather than here. Do not edit generated files by hand; regenerate them from their workflow or analysis script.
