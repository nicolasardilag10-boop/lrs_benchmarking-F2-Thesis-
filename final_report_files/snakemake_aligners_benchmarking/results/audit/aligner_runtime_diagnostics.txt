VACmap - a long-read aligner for structural variation discovery

options:
  -h, --help            show this help message and exit

Required Arguments:
  -ref REF              Path to reference FASTA file
  -read READ [READ ...]
                        Path to read file(s). Supports wildcards (e.g., *.fastq).
  -mode {H,L,S,R,asm}   Alignment mode:
                         H   : High error rate long reads (PacBio CLR, ONT)
                         L   : Low error rate long reads (PacBio HiFi)
                         asm : Assembly mode
                         S   : Sensitive mode
                         R   : No prefer closer mode

Output Arguments:
  -o O                  Output path (default: stdout). Must end in .sam, .bam, or .sorted.bam if writing to a file. (Note: Output will be sorted if the path ends in .sorted.bam).
  --force               Overwrite output file if it exists.
  --nowriteindex        Do not save the reference index for reuse.

Alignment Parameters:
  -t T                  Number of threads (default: 8)
  -k K                  Kmer size (default: 15)
  -w W                  Minimizer window size (default: 10)
  -c C                  Top N clusters (default: 100)
  -maxdivergence MAXDIVERGENCE
                        Max sequence divergence (default depends on mode)

Penalties:
  -globalpenalty GLOBALPENALTY
                        Global variation penalty
  -localpenalty LOCALPENALTY
                        Local variation penalty
  -globalmaxdiff GLOBALMAXDIFF
                        Global max diff (default: 50)
  -localmaxdiff LOCALMAXDIFF
                        Local max diff (default: 30)

Flags:
  --eqx                 Output =/X CIGAR operators for sequence match/mismatch.
  --MD                  Output the MD tag.
  --cs [CS]             Output the cs tag. Usage: --cs or --cs=long
  --L                   Write CIGAR with >65535 operators at the CG tag (cigar2cg).
  --markunbalancetra    Set MAPQ of unbalanced translocation subalignment to 1.
  --nodiscard           Keep subalignments where surrounding indel sizes are similar.
  --copycomments        Copy FASTA/Q comments to output.
  --H                   Use hard-clipping instead of soft-clipping.
  --fakecigar           Use approximate CIGAR in the SA tag.
  --Q                   Ignore base quality in the input file.
  --debug               Enable debug mode.
  -workdir WORKDIR      Working directory (Required if mode is 'asm')

Read-group (RG) metadata:
  --rg-id STRING        Adds RG:Z:<string> to all alignments (required when using other --rg-* flags).
  --rg-sm STRING        RG header: Sample (SM).
  --rg-lb STRING        RG header: Library (LB).
  --rg-pl STRING        RG header: Platform (PL).
  --rg-ds STRING        RG header: Description (DS).
  --rg-dt YYYY-MM-DD    RG header: Date (DT).
  --rg-pu STRING        RG header: Platform unit (PU).
  --rg-pi INT           RG header: Median insert size (PI).
  --rg-pg STRING        RG header: Programs (PG).
  --rg-cn STRING        RG header: Sequencing center (CN).
  --rg-fo STRING        RG header: Flow order (FO).
  --rg-ks STRING        RG header: Key sequence (KS).
  --rg-pm STRING        RG header: Platform model (PM).
  --rg-bc STRING        RG header: Barcode sequence (BC).
