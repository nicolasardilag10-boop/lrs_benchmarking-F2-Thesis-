# Reports and report-facing exports

This directory is the organized destination for report-ready exports. The currently maintained F2 manuscript remains in [`../final_report_files/`](../final_report_files/README.md) to preserve its established build paths.

- `final/`: final report exports.
- `figures/`: figures copied or linked specifically for report assembly.
- `tables/`: report-ready tables.
- `supporting/`: supplementary material.
- `f2/`: F2-specific report organization.

Avoid creating a second canonical copy of a scientific figure or table. Link to the analysis module whenever possible.
