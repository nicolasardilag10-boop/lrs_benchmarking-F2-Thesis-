# Imported 30× samtools statistics

Source `samtools stats` summaries for the 30× alignment benchmark. These files are preserved as imported evidence and should not be edited manually.

- `*.cram.stats.SN.txt`: summary-number extracts for minimap2 and pbmm2 runs.
- `vacmap_vg_stats/`: full statistics for VACMap and VG runs.
- `alignment_summary_30x_samtools.tsv`: imported aggregate table.

The curated analysis output is [`../alignment_analysis/tables/30x/final/alignment_benchmark_30x.tsv`](../alignment_analysis/tables/30x/final/alignment_benchmark_30x.tsv).
