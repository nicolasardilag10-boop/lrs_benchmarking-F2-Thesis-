# Run metrics

This directory contains legacy/shared runtime metric extraction material. The canonical 30× alignment benchmark combines validated runtime, CPU, and RAM metrics in [`../alignment_analysis/tables/30x/final/alignment_benchmark_30x.tsv`](../alignment_analysis/tables/30x/final/alignment_benchmark_30x.tsv).

- [`create_run_metrics.sh`](create_run_metrics.sh): runtime summary helper.
- [`mm2.run_metrics.tsv`](mm2.run_metrics.tsv): minimap2 run-metric source table.
