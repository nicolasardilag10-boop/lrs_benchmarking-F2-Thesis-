# Project documentation

Use this directory for maintained project-wide documentation. Module-specific commands belong in the README nearest the code they describe.

| Document | Purpose |
|---|---|

## Supporting documentation

- `inventories/`: tool and container inventories.
- `methodology/`: analysis methods, study guides, and tool-selection records.
- `cleanup_audit/`: historical repository-cleanup reports; not scientific results.
- `variant_caller_validation/`: validation records for caller environments.
- `lrs_shortcuts.sh`: optional shell navigation shortcuts.

The authoritative project constraints are in [`../CONSTITUTION.md`](../CONSTITUTION.md).
